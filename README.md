# 📊 Retail Customer Behavior and Shopping Trends Analysis

An end-to-end **Data Analytics** project that demonstrates the complete workflow of **data preprocessing, database integration, SQL analysis, and interactive dashboard development** using **Python**, **PostgreSQL**, and **Power BI**.

The objective of this project is to analyze customer shopping behavior, identify purchasing patterns, and generate actionable business insights through an interactive dashboard.

---

## 🚀 Project Overview

This project follows the complete Data Analytics pipeline:

- 🧹 Data Cleaning & Preprocessing using Python
- 🗄️ PostgreSQL Database Integration
- 📈 Business Analysis using SQL
- 📊 Interactive Dashboard Development in Power BI
- 💡 Business Insight Generation

---

## 🎯 Business Objectives

This project aims to answer important business questions, including:

- Which customer segment contributes the most revenue?
- Which product categories generate the highest sales?
- Do subscribed customers spend more than non-subscribed customers?
- Which products receive the highest customer ratings?
- Which products are most frequently purchased with discounts?
- Which age group contributes the highest revenue?
- Are repeat customers more likely to subscribe?
- Which products are the top performers within each category?

# 🧹 Data Preprocessing

The dataset was cleaned and transformed using **Python (Pandas)** before loading it into PostgreSQL.

### Data Cleaning Steps

- Loaded the raw customer shopping dataset.
- Performed Exploratory Data Analysis (EDA).
- Checked dataset information and descriptive statistics.
- Identified missing values.
- Filled missing **Review Rating** values using the median review rating of each product category.
- Standardized column names by converting them to lowercase and replacing spaces with underscores.
- Renamed `purchase_amount_(usd)` to `purchase_amount`.
- Created **Age Groups** using quartile-based segmentation.
- Converted purchase frequency into numerical days for easier analysis.
- Validated duplicate information between **Discount Applied** and **Promo Code Used**.
- Removed redundant columns.
- Uploaded the cleaned dataset into PostgreSQL using SQLAlchemy.
